# Repository Overview

This repository is a personal code collection and sandbox for multiple projects, experiments, and learning exercises. It serves as a single location to track ideas and implementations across different domains, languages, and toolchains.

## Purpose

- Showcase practical coding projects and prototypes.
- Keep reusable examples and reference implementations in one place.
- Support personal learning and experimentation.
- Enable easy sharing of progress and work with collaborators.

## Structure

Each project lives in its own folder or top-level artifact, with a dedicated README and clear instructions:

- `go-movies-crud` (current project): simple CRUD API for movies in Go.
- `project-name-2`: another project sample (replace as needed).
- `project-name-n`: additional project directories.

## How to Use

1. Explore folders for individual projects.
2. Read each project README for setup and run instructions.
3. Clone the repository and work in your local environment.

## Contribution

- Add a new project directory with a descriptive name.
- Include a README for intent, setup, and usage.
- Keep commits atomic and document changes.
